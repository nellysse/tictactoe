# Tic-Tac-Toe Game 🎮

Классическая игра "Крестики-нолики" с графическим интерфейсом на JavaFX и встроенным AI-противником.

## 📋 Описание

Это полнофункциональная реализация игры Tic-Tac-Toe (Крестики-нолики) с двумя режимами игры:
- **Игрок против Игрока** - классический режим для двух игроков
- **Игрок против AI** - играйте против умного компьютерного противника

## ✨ Особенности

- 🎨 Современный графический интерфейс на JavaFX
- 🤖 Умный AI-противник с стратегическим мышлением
- 🎯 Подсветка выигрышной комбинации
- 🔄 Быстрый перезапуск игры
- 🎭 Переключение между режимами игры
- 💯 Определение ничьей

## 🏗️ Архитектура

Проект построен по паттерну **MVC (Model-View-Controller)**:

```
org.example.xose/
├── GameModel.java          # Модель игры (логика, состояние)
├── GameView.java           # Представление (UI)
├── HelloController.java    # Контроллер (обработка событий)
├── AIPlayer.java          # Логика AI-противника
└── HelloApplication.java  # Точка входа приложения
```
### Компоненты

- **GameModel** - управляет состоянием игры, проверяет победителя
- **GameView** - отрисовывает интерфейс и обрабатывает визуальные обновления
- **HelloController** - связывает модель и представление, обрабатывает клики
- **AIPlayer** - реализует стратегию AI (победа → блокировка → центр → углы)

## 🚀 Запуск

### Требования

- Java 11 или выше
- JavaFX SDK

## 🎮 Как играть

1. Запустите приложение
2. Выберите режим игры кнопкой **"Mode"**
3. Кликайте по ячейкам для совершения хода
4. Игрок **X** всегда ходит первым
5. Для новой игры нажмите **"New Game"**

## 🤖 Стратегия AI

AI-противник использует следующую приоритетную стратегию:

1. **Победа** - если есть возможность выиграть, делает победный ход
2. **Блокировка** - блокирует победный ход игрока
3. **Центр** - занимает центральную клетку, если свободна
4. **Углы** - предпочитает угловые позиции
5. **Любая клетка** - занимает любую свободную клетку
