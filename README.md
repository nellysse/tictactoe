# tictactoe
🎮 JavaFX Крестики-Нолики (Tic-Tac-Toe)
Это классическая игра "Крестики-Нолики" (Tic-Tac-Toe), реализованная с использованием фреймворка JavaFX. Проект использует стандартный шаблон Model-View-Controller (MVC) с отдельными файлами .java и .fxml для чистой и масштабируемой архитектуры.
Цель: Продемонстрировать базовую игровую логику, управление состоянием игры, обработку событий мыши/кнопок и принципы объектно-ориентированного программирования (ООП) в среде JavaFX.
Режим игры: Игрок против Игрока (PvP) по умолчанию.
Интерфейс: Графический интерфейс, реализованный с помощью JavaFX.

Features (Функционал)
Графический интерфейс (GUI) с полем 3x3.
Проверка победы по горизонтали, вертикали и диагонали.
Обработка ничьей и вывод сообщения о результате.
Сброс игры для начала нового раунда.
Простая и понятная логика хода, управляемая событиями мыши.
